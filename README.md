# Edwin's Personal Website

Static single-page site served by GitHub Pages: `index.html` and `styles.css`, no build step.

## Assets

- `favicon.svg` is the logo mark (also used in the header); `images/apple-touch-icon.png` is a 180px render of it
- `images/contours.svg` is the hero's contour-line motif, applied as a CSS mask so it follows the light/dark theme
- `images/social-card.png` is the 1200x630 link preview image
- `images/profile-480.jpg` is the resized photo shown on the page; `images/profile.JPG` is the full-size original
